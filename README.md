# ToDo Vibe 📝

ToDo Vibe is a smart and minimal task management web application that helps users organize their daily tasks efficiently.

## 🚀 Features
- Add, delete, and complete tasks
- Filter tasks (All / Completed / Pending)
- Data persistence using Local Storage
- Clean and minimal UI
- Responsive design

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

Currently under active development.
